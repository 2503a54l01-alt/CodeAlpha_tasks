# 
🚀 CodeAlpha Java Programming Internship Projects

This repository contains my Java projects completed as part of the CodeAlpha Java Programming Internship. These projects demonstrate the practical implementation of Core Java, Object-Oriented Programming (OOP), Collections, File Handling, Exception Handling, and Menu-Driven Console Applications.

📂 Projects Included

1️⃣ Student Grade Tracker

📖 Overview

The Student Grade Tracker is a Java console application that manages student academic records. It allows users to add student details, enter marks, calculate total marks, average percentage, assign grades automatically, and display student reports.

✨ Features

Add student details
Enter marks for multiple subjects
Calculate total marks
Calculate average percentage
Automatically assign grades
Display complete student reports
Menu-driven interface
Input validation
🛠 Technologies Used

Java
Object-Oriented Programming (OOP)
ArrayList
Scanner
Exception Handling
2️⃣ Hotel Reservation System

📖 Overview

The Hotel Reservation System is a Java console-based application designed to manage hotel room bookings efficiently. It allows users to search available rooms, reserve rooms, cancel bookings, calculate billing based on stay duration, and permanently store booking records using File Handling.

✨ Features

View available rooms
Search rooms by category
Book hotel rooms
Validate 10-digit phone numbers
Calculate total room charges
Generate unique Booking IDs
View booking history
Cancel bookings
Automatically update room availability
Store booking records using File I/O
Menu-driven interface with exception handling
🛠 Technologies Used

Java
Object-Oriented Programming (OOP)
ArrayList
File Handling
LocalDateTime API
Exception Handling
🚀 How to Run

Compile

javac Main.java

Run

java Main
